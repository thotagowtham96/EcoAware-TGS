# 🌿 EcoAware – Environmental Awareness Platform

## Project Overview
EcoAware is a centralized environmental awareness platform that provides information about environmental issues, waste management, conservation, and eco-friendly practices.

## Objectives
- Spread environmental awareness.
- Educate users about waste management.
- Encourage water and energy conservation.
- Promote sustainable lifestyles.
- Provide centralized environmental resources.

## Key Features
- Home page with environmental information.
- Environmental issues and solutions.
- Waste management guidance.
- Conservation tips.
- Eco-friendly practices.
- User registration and login.
- User dashboard.
- Admin panel for resource management.
- MySQL database integration.

## Technologies Used

## Installation and Setup

1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin at `http://localhost/phpmyadmin`.
5. Create a database named `ecoaware_db`.
6. Import the `ecoaware_db.sql` file.
7. Configure database credentials in `db.php`.
8. Open the project using:

```text
http://localhost/EcoAware-TGS/
```

Change the URL if your local project folder has a different name.
